# 生产管理系统（工序流转平台）

一套自建的生产 / 工序流转管理系统，复刻主流 MES 的工单管理流程，支持局域网多终端同时使用。

## 功能
- 登录账号、管理员/操作员权限
- 工单管理：创建工单、按工序流转（开始 → 逐道完成 → 完工 / 退回 / 取消 / 恢复）、良品与不良数量记录
- 工艺路线：自定义工序及顺序（默认 9 道：来料检 → 放码 → 调色 → 造模 → 刷胶 → 贴膜 → 开缝 → 包装 → 检验）
- 产品物料、销售订单、库存出入库
- 车间看板（按工序显示在制工单）、工作台统计、报表分析（良品/不良/良率）
- 工单导出 CSV、全量数据备份 / 恢复

## 启动方法（Windows）
1. 安装 Node.js（https://nodejs.org/zh-cn ，LTS 版，一路下一步）。
2. 双击 `start.bat`，按窗口提示访问地址（本机 http://localhost:3000 ，局域网用显示的 IP）。

## 默认账号
- 管理员：admin / admin123（首次登录后请在「系统设置」里修改）
- 操作员：worker / 123456

## 局域网多人使用
- 服务器电脑启动后，同一局域网内其他电脑/手机浏览器访问窗口里显示的 `http://服务器IP:3000` 即可。
- 数据保存在本机 `data/app.db`，请定期用「系统设置 → 数据备份」下载备份。

## 目录结构
- server.js  后端服务（Node 内置模块 + SQLite，无需安装任何第三方依赖）
- public/    前端页面
- data/      数据库文件（运行时自动生成）
